# Design System administrativo MiTiendaPesca
Referencia visual: Tabler (MIT). Flujos comerciales: falcolee/e-commerce-dashboard (MIT).
Fuentes: https://docs.tabler.io/ui/components y https://github.com/falcolee/e-commerce-dashboard

## Implementado
CSS propio en public_html/assets/css/admin-v3/components/design-system.css.
Contrato opt-in av3-ui- para tarjetas, encabezados, botones, campos, tablas, filtros y estados.
Primera integración: /admin/analytics. Sin Bootstrap, React ni Tailwind añadidos.
No modificar las clases del sidebar ni las clases genéricas del sistema anterior.
